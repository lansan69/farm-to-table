02

Estructura de carpetas

Dentro de tu carpeta asignada van exactamente 3 archivos con el mismo nombre que la carpeta:

app/logged/user/main-content/ ├── marketplace/ ← ejemplo: tu carpeta │ ├── marketplace.html ← estructura │ ├── marketplace.css ← estilos │ └── marketplace.js ← lógica y render() │ ├── chats/ │ ├── chats.html │ ├── chats.css │ └── chats.js │ └── ← no toques otras carpetas
✕ Nunca modifiques archivos fuera de tu carpeta asignada. Ni el nav, ni global.css, ni app.js, ni archivos de otro compañero.
03

Los 3 archivos que debes crear

Usa marketplace como ejemplo. Reemplaza el nombre con el de tu pantalla.

marketplace.html — Solo el contenido

No incluyas <html>, <head> ni <body>. Solo el HTML de tu pantalla:

HTML <!-- marketplace.html --> <!-- Solo el contenido de tu pantalla, sin html/head/body --> <section class="marketplace"> <div class="marketplace__header"> <h1>Marketplace</h1> <input type="search" placeholder="Buscar productos..."/> </div> <div class="marketplace__grid" id="product-grid"> <!-- Las tarjetas se inyectan desde marketplace.js --> </div> </section>

marketplace.css — Solo tus estilos

Usa el nombre de tu pantalla como prefijo en todas las clases para no chocar con otros:

CSS /* marketplace.css */ /* Usa variables de global.css — no redeclares colores hardcoded */ .marketplace { padding: 32px; max-width: 1200px; margin: 0 auto; } .marketplace__header { display: flex; justify-content: space-between; align-items: center; margin-bottom: 24px; } .marketplace__grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(240px, 1fr)); gap: 20px; } /* ── Responsive ── */ @media (max-width: 768px) { .marketplace { padding: 16px; } .marketplace__grid { grid-template-columns: 1fr; } }

marketplace.js — El render()

Este es el archivo más importante. El router llama a marketplace.render() cuando el usuario navega a tu pantalla:

JS // marketplace.js // REGLA: exporta siempre una constante con el nombre de tu pantalla en camelCase const marketplace = { render() { // 1. Apunta al contenedor principal const el = document.getElementById('main-content'); // 2. Inyecta tu HTML el.innerHTML = ` <section class="marketplace"> <div class="marketplace__header"> <h1>Marketplace</h1> <input type="search" placeholder="Buscar productos..."/> </div> <div class="marketplace__grid" id="product-grid"></div> </section> `; // 3. Inicializa la lógica después de inyectar el HTML this.init(); }, init() { // Aquí van event listeners, fetch de datos, etc. const grid = document.getElementById('product-grid'); // grid.innerHTML = '...' ← aquí conectarás el API después } };
⚠ El nombre de la constante debe ser camelCase del nombre de tu carpeta. mis-lotes → const misLotes, catalogo-vendedores → const catalogoVendedores.
04

Ver tu pantalla en el browser

Con XAMPP corriendo, abre directamente la URL de tu ruta:

URL // Usuario http://localhost/farm-to-table/usuario/marketplace http://localhost/farm-to-table/usuario/chats http://localhost/farm-to-table/usuario/perfil // Productor http://localhost/farm-to-table/productor/mis-lotes http://localhost/farm-to-table/productor/publicar-lote
  1. Abre XAMPP y asegúrate que Apache esté corriendo (botón Start)
  2. Abre el browser y escribe la URL de tu pantalla exactamente como aparece en la tabla de rutas
  3. Deberías ver el nav del proyecto ya montado y tu contenido debajo
  4. Edita tu .html y .css — recarga el browser con Ctrl+Shift+R para ver cambios
✓ Si el nav no aparece, verifica que XAMPP esté corriendo y que la URL sea exactamente igual a la de la tabla — sin mayúsculas, sin espacios.
05

Navegar entre pantallas

Para ir a otra pantalla desde un botón o link, usa siempre window.location.hash. Nunca uses href con rutas absolutas ni window.location.href.

✓ CORRECTO window.location.hash = '#/usuario/marketplace'; <button onclick=" window.location.hash = '#/usuario/marketplace' ">Ver Marketplace</button>
✕ INCORRECTO window.location.href = '/marketplace'; <a href="/usuario/marketplace"> Ver Marketplace </a> <a href="marketplace.html">...</a>

Rutas disponibles para navegar

JS // Comprador window.location.hash = '#/usuario/marketplace'; window.location.hash = '#/usuario/informacion-producto'; window.location.hash = '#/usuario/catalogo-vendedores'; window.location.hash = '#/usuario/perfil'; window.location.hash = '#/usuario/chats'; window.location.hash = '#/usuario/productos-favoritos'; window.location.hash = '#/usuario/vendedores-favoritos'; window.location.hash = '#/usuario/contraofertas'; window.location.hash = '#/usuario/calificar-producto'; // Productor window.location.hash = '#/productor/mis-lotes'; window.location.hash = '#/productor/publicar-lote'; window.location.hash = '#/productor/editar-lote'; window.location.hash = '#/productor/perfil'; window.location.hash = '#/productor/chats'; window.location.hash = '#/productor/contraofertas';

CSS

⚠ Usa siempre las variables de global.css para colores, radios y sombras. Nunca pongas colores hardcoded como #1e6b4a — usa var(--color-primary).

JS

⚠ Nunca uses document.write() ni alert(). Toda interacción va dentro del render() o el init() de tu constante.

Responsivo

✓ Todas las pantallas deben verse bien en móvil (360px) y desktop (1280px). Usa @media (max-width: 768px) como breakpoint principal.
07

Entregar tu trabajo con Git

  1. Trabaja siempre en tu rama — nunca hagas commits directo a main
  2. Solo agrega los archivos de tu carpeta al commit
  3. Cuando tu pantalla se vea igual al diseño de Figma, abre un Pull Request
  4. Alan revisa y hace el merge — no te mergees tú mismo
BASH # Flujo de trabajo diario git checkout -b feature/marketplace # tu rama git add app/logged/user/main-content/marketplace/ # solo tu carpeta git commit -m "feat: pantalla marketplace HTML+CSS" git push origin feature/marketplace # sube tu rama # → Abre Pull Request en GitHub
✕ Nunca hagas git add . — podrías subir archivos de otros compañeros o archivos de configuración sensibles. Siempre especifica tu carpeta.
✓ ¿Algo no funciona o tienes dudas del router? Mándale mensaje a Alan antes de hacer el PR. Es más fácil corregir antes que después del merge.
