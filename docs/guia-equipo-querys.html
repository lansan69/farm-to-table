PASO 01

Instalar TablePlus

TablePlus es un cliente visual de bases de datos. Te permite conectarte a la BD del proyecto y ejecutar tus consultas sin necesitar XAMPP ni PHP.

↓ Descargar TablePlus
⚠ La versión gratuita tiene límite de 2 tabs abiertos — es más que suficiente para este proyecto. No necesitas pagar nada.
  1. Descarga el instalador desde tableplus.com según tu sistema operativo (Windows / Mac / Linux)
  2. Instala normalmente y abre la aplicación
  3. En la pantalla de inicio haz clic en "Create a new connection"
  4. Selecciona MySQL como tipo de conexión

PASO 03

Hacer tus consultas

Una vez conectado, abre el editor SQL:

  1. Haz clic en el ícono SQL en la barra superior (o presiona CMD/CTRL + T)
  2. Escribe tu consulta en el editor
  3. Presiona CMD/CTRL + Enter para ejecutar
  4. Los resultados aparecen en la tabla debajo — puedes ver filas, columnas y errores claramente

Ejemplo de consulta

SQL -- Ver todos los productos disponibles SELECT cp.id, cp.nombre_producto, cp.precio_unitario, cp.cantidad_disponible, u.nombre AS agricultor FROM catalogo_productos cp JOIN usuarios u ON cp.usuario_id = u.id WHERE cp.cantidad_disponible > 0 ORDER BY cp.nombre_producto;
⚠ Prueba siempre tu consulta con LIMIT 10 primero para no traer miles de filas de golpe.
PASO 04

Transformar en vista

Cuando tu consulta funcione correctamente, conviértela en un CREATE VIEW. Las vistas son las que el backend va a consumir en los modelos PHP.

Estructura de una vista

SQL -- Vista: productos disponibles por agricultor -- Devuelve: id, nombre, precio, stock, agricultor -- Autor: tu nombre -- Fecha: 2025-05-21 CREATE OR REPLACE VIEW productos_disponibles AS SELECT cp.id, cp.nombre_producto, cp.precio_unitario, cp.cantidad_disponible, u.nombre AS agricultor FROM catalogo_productos cp JOIN usuarios u ON cp.usuario_id = u.id WHERE cp.cantidad_disponible > 0;
✓ Usa siempre CREATE OR REPLACE VIEW — así si necesitas corregirla no da error al volver a ejecutar.
PASO 05

Guardar y entregar

Cada quien tiene su propia carpeta dentro de querys/ en el repositorio. Guarda tus archivos ahí — uno por vista.

Estructura del repositorio

querys/ ├── tu_nombre/ ← tu espacio, solo tú tocas esto │ ├── productos-disponibles.sql │ ├── historial-ordenes.sql │ └── reputacion-agricultores.sql ├── nombre_compañero/ │ └── vista-entregas.sql └── otro_compañero/ └── zonas-activas.sql

Nombre de los archivos

Usa kebab-case describiendo lo que devuelve la vista:

Ejemplos ✅ productos-disponibles.sql ✅ historial-ordenes-usuario.sql ✅ agricultores-con-reputacion.sql ❌ MiVista.sql ❌ consulta1.sql ❌ vista_productos.sql

Pasos para entregar

  1. Copia tu CREATE OR REPLACE VIEW en un archivo .sql dentro de querys/tu_nombre/
  2. Asegúrate de que el archivo tenga el comentario de cabecera con qué devuelve, tu nombre y la fecha
  3. Haz commit y push a tu rama
  4. Abre un Pull Request a main — Alan lo revisa y hace el merge
⚠ No modifiques archivos fuera de tu carpeta querys/tu_nombre/. Nunca toques schema.sql ni dump.sql.
✓ ¿Dudas? Mándale mensaje a Alan antes de hacer el PR. Es más fácil corregir antes que después del merge.
